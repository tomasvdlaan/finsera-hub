## Steps

1. Open the draft quote.
2. Click **delete draft** (red text link next to **Send quote**).
3. You return to the quote list.

## Good to know

- There is **no confirmation dialog**. The click deletes immediately and it cannot be undone.
- Only drafts can be deleted. A sent quote cannot be deleted ("reject it instead"): see [Mark a quote rejected](help:sales/reject-quote).
- Needs `sales.quotes.write`.
- Deleting is recorded in the audit trail.
