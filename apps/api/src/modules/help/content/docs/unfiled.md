The **Unfiled** page lists files in the platform's SharePoint library that have no document record yet. Filing one gives it a record, so it becomes searchable and can be linked, shared and asked questions. Nothing is copied: the file stays where it is.

## Before you start

- You need `docs.write`.
- The platform must be connected to SharePoint. Otherwise the page shows a short message instead of a list.
- You reach the page from the **N unfiled** link next to the search box on **Documents**. It only appears when there is something to file.

## Steps

1. Open **Unfiled**. Each row shows the file name, its folder path, size, last change and who changed it.
2. Adjust the **Title** if you wish. It starts as the file name without its extension.
3. Under **Belongs to…** choose where it goes:
   - **Finsera (no client)**: for templates and quotes for prospects.
   - a client, or a project.
4. Click **File it**.

The row disappears and the document is on the Documents list. If you forgot step 3 you see "Choose where this document belongs first".

## Good to know

- It lists only the platform's own library, not other SharePoint areas.
- A file never appears again once filed, but a file someone drops in later will turn up here the next time anybody opens the page.
- A filed document has a version labelled **filed from the library**, its text is read for search, and it is linked to the client or project.
- Documents filed with **Finsera (no client)** have no client, so they cannot be shared with a client and do not show up under any client filter.
- The **All documents** button top right returns to the list.
