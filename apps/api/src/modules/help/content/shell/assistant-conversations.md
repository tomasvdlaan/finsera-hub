Every conversation you have with the assistant is kept. The list on the left of the assistant page is how you find, file and clean them up.

## The list

Conversations are grouped by date, newest first, with pinned ones at the top. Each row shows its title; small icons show if it is pinned, archived, about a particular record, or tagged. At the top:

- **Search** - searches your conversations. While searching, each row shows a snippet of why it matched.
- **+** (New conversation).
- **Sort** - **Recent**, **Oldest** or **A-Z**.
- **All tags** - a filter, shown only when your organisation has tags set up.
- **Show archived** - toggles archived conversations.
- The star - [Saved answers](help:shell/assistant-saved-answers).
- **New folder**.
- While a filter is active: **Save this search** and **Clear filters**.

## Steps

### Rename, pin, archive, export, delete one
1. Select the **⋯** on a row (**Actions for …**).
2. Choose **Rename**, **Pin to top** / **Unpin**, **Archive** / **Unarchive**, **Export**, or **Delete**.
   - **Export** downloads the thread as a Markdown file with each question and answer.
   - **Delete** removes the whole thread including its answers. This cannot be undone. **Archive** keeps it, out of the way.
3. Other entries in the menu: **Select** (start a multi-select), **Where does this belong?** (names the record the answers cited, or says "Nothing cited yet."), and any tags that exist, to switch them on or off.

### File into folders
1. Select **New folder**, give a name and, optionally, an emoji.
2. Drag a conversation onto a folder. Drag it onto the **Unfiled** area to take it out again.
3. A folder's **⋯** menu has **Rename, emoji, order**, **Folder inside** (one level of nesting), **Show only this**, and **Delete folder**. Deleting a folder keeps the conversations; they move back to the top level.

### Act on several at once
1. Choose **Select** from a conversation's menu. Checkboxes appear.
2. Tick the ones you want. A bar shows the count with **Move…** (to a folder or **Top level**), archive, pin, and delete.
3. Deleting several asks you to confirm and cannot be undone.

### Save a search
1. Filter the list (search text, folder, tag, archived, sort).
2. Select **Save this search** and name it. It appears as a chip under the toolbar and always shows the current matches.
3. To remove a saved search, right-click its chip.

## Good to know

- A conversation is given a title automatically; rename it any time.
- **Split here** on an answer (see [The assistant](help:shell/assistant)) is how you separate a thread that wandered into a second subject.
- The list only holds your own conversations.
