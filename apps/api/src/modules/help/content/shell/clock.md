The clock in the top bar is always there, so you can see - and stop - a running timer from any page. Logging hours is described in [Time](help:time/index); this page is only about the bar.

## What it shows

- **No timer running:** a button reading **Start a timer**. Selecting it opens the **Time** page, where you choose what you are working on and start the timer.
- **A timer running:** the elapsed time (hours:minutes:seconds) and the project name, highlighted in the accent colour. Selecting the time or name opens the **Time** page. The square **■** button stops the timer.

## Steps to stop a timer

1. Select **■** in the top bar.
2. The elapsed time is saved as an entry.

## Good to know

- The bar checks the server every 30 seconds and whenever you return to the tab, so a timer started on another device shows up here too.
- If a timer has run **for more than 24 hours**, it cannot be saved as elapsed time. The **■** button then sends you to the **Time** page, where you say how long you actually worked. (Its tooltip says: "Running over a day - stop it on the Time page and say how long you worked".)
- The assistant can also start and stop timers for you. See [What the assistant can and cannot do](help:shell/assistant-limits).
