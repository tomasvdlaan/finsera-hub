**All work** answers "what is on the whole plate?" - every open card from every project in one view. It is also the hub for the **Work** section of the platform.

## What you see

- **A tab strip** at the top for the **Work** section. It lists **Meetings**, **Board**, **All work**, **Client tickets** and **Whiteboards**, so the pages in this section that have no place in the top bar can be reached from here.
- **A project filter**, set to **All projects**, and a count of "open cards".
- **Three lanes:** **To do**, **In progress** and **Waiting**, each with the number of cards in it. Done cards are not shown.
- Each **card** shows its title; a red **blocked** tag and the reason if it is blocked; and a line with its project, due date (`due 2026-11-03`), priority if not normal, and labels. Selecting a card opens it.

## Steps

### Look at one project
1. Choose a project in the filter at the top. The count and lanes narrow to that project.
2. Choose **All projects** to widen again.

### Open a card
1. Select its title. The card's own page opens at `/tasks/…`. See [The board](help:scrum/index).

## Good to know

- **It is read-only.** You cannot drag cards here. Moving a card between columns happens on its project's board, because a card can only move to a column that its own project has. See [The board](help:scrum/index).
- The lanes group by what a column *means* (not started, active, waiting), so they stay right even if a project renamed its board columns.
- With nothing open you see "Nothing open", and a hint that cards come from any project's board and from meeting action points once you accept them.
- The **Waiting**, **In progress** and **Overdue** counts on [Today](help:shell/today) link here.
