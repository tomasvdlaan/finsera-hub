The platform has a small set of shortcuts. None of the single-letter ones fire while you are typing in a box.

## Everywhere

| Keys | What it does |
|---|---|
| **⌘K** / **Ctrl+K** | Open or close the [command bar](help:shell/command-bar) |
| **Esc** | Close the command bar, the avatar menu, or a widget's settings panel |

## In the command bar

| Keys | What it does |
|---|---|
| **↑** / **↓** | Move through the list |
| **↵** (Enter) | Open the highlighted row |
| **Esc** | Close |

## On the assistant page

| Keys | What it does |
|---|---|
| **⌘⇧O** / **Ctrl+Shift+O** | Start a new conversation |
| **Enter** in the box | Send the question |

## On the board

| Keys | What it does |
|---|---|
| **n** | Open the new-card box and focus it |
| **f** | Open the filters and focus the first one |
| **Esc** | Close the open panel; otherwise close the card preview and clear the filters |
| **←** / **→** (in an open card) | Go to the previous or next card in the column |

See [The board](help:scrum/index).

## In a comment

| Keys | What it does |
|---|---|
| **@** then letters | Suggest colleagues to mention |
| **↑** / **↓** | Move through suggestions |
| **Enter** or **Tab** | Insert the highlighted colleague |
| **Esc** | Dismiss suggestions |

See [Comments and mentions](help:shell/comments).

## Arranging Today

While editing your dashboard, you can reorder a widget without a mouse: focus it, press Space, move with the arrow keys, press Space again. See [Arrange your dashboard](help:shell/arrange-dashboard).

## Good to know

- **⌘K** works from inside a meeting room and a whiteboard as well.
- The browser keeps **⌘N** for itself, which is why a new assistant conversation uses **⌘⇧O**.
